# CurveSmear — Study 02

`index.html` をブラウザで開いてください。インストールやサーバーは不要です。

画像を固定表示し、カーブの周囲だけを変形する静止画デモです。

- 画像を読み込み、変形したい部分の上にカーブの4点をドラッグします。
- Radiusはカーブからの影響半径です。青い帯が影響範囲を示します。
- Smear量で引き伸ばし、境界のぼかしで範囲の端の強さを調整します。
- 筋の強さを0にすると基本の変形を確認できます。
- 流れを反転できます。矢印が素材を伸ばす方向です。
- 元画像を残す量は、変形画像と同じ位置の元画像を混ぜる割合です。
- 元画像との比較、ガイドなしの透過PNG保存に対応しています。
- 読み込んだ画像はブラウザ内で処理され、送信されません。

## 処理と制約

画像全体を縦横比を維持して800×520内に収めます。カーブ編集では入力画像の位置・サイズ・向きは変えません。
カーブの弧長・法線座標を使い、元の座標からの差分として逆変換します。
Smear量は伸長の制御値で、各ピクセルの実移動距離ではありません。
Radius外は元画像をそのまま保持し、内側では距離に応じて変位を弱めます。
筋は法線方向の固定ノイズで変位量を変えて作ります。
これは一般的な流体シミュレーションではなく、1本の曲線による局所変形の試作です。
半径はカーブ全体で共通です。自由形状の追加マスクや複数カーブにはまだ対応していません。
Radiusは出力の変形範囲を制限します。読み取る元画像の領域を限定する素材選択マスクではありません。
背景付き画像では範囲内の背景も変形します。
鋭い曲がり・自己交差・狭いRadiusで大きく伸ばす場合は継ぎ目や折り返しが出ることがあります。
画像端で出力は切れます。元サイズでの書き出し、動画、AEへの組み込みは未対応です。
