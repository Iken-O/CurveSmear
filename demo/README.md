# CurveSmear — Study 04

`index.html` をブラウザで開いてください。インストールやサーバーは不要です。

画像を固定表示し、カーブの周囲だけを変形する静止画デモです。

## 幅方向の倍率グラフ

「刀身で試す」で比較用の素材と円弧を読み込みます。`index.html?scene=sword` からも直接開けます。
この操作は素材・パス・Smear量450・Radius100・境界のぼかし0・筋0・元画像との混合0・通常方向・L1→R100を設定します。

- 横軸は幅方向のL端→中心→R端、縦軸は伸び倍率0〜100%。パスの始点→終点ではありません。
- 「均一100%」は従来の変形。「L1→R100」はL側を抑え、「剣先側だけ伸ばす」はR側へ寄せた曲線です。
- グラフをクリックして中間点を追加し、ドラッグで移動。選択した中間点は削除ボタンかDeleteキーで削除します。端点は削除できません。
- L/Rの端点は数値でも入力できます。「なめらかな曲線」を外すと点同士を直線で結びます。
- Lは正の法線側（橙）、Rは負の法線側（青）。刀身シーンではLが根元、Rが剣先側です。S字でも内外を自動判定して入れ替えません。
- 「L/Rを入れ替え」は倍率分布を左右反転します。「流れを反転」は倍率分布を変えません。
- 倍率は既存処理が計算したパス上の変位に掛けます。0%で変位なし、100%で従来の変位。境界のぼかし・筋・元画像との混合は別途効きます。
- 曲線補間は点間で値が行き過ぎないHermite補間を使い、0〜100%に収めています。
- PNG保存にはグラフやガイドを含みません。編集内容の保存・アニメーションはこのデモにはありません。

## 基本操作

- 画像を読み込み、変形したい部分の上にカーブの4点をドラッグします。
- Radiusはカーブからの影響半径です。青い帯が影響範囲を示します。
- Flatは始点・終点を接線に直角に切り、Roundは従来どおり半円状に広げます。初期値はFlatです。
- Flat端にはぼかしを適用せず、境界のぼかしはリボンの左右にのみ適用します。
- テスト素材の赤い円は終点より先にある比較物です。Flatでは保持され、Roundでは変形範囲に入ります。
- Smear量で引き伸ばし、境界のぼかしで範囲の端の強さを調整します。
- 筋の強さを0にすると基本の変形を確認できます。
- 流れを反転できます。矢印が素材を伸ばす方向です。
- 元画像を残す量は、変形画像と同じ位置の元画像を混ぜる割合です。
- 元画像との比較、ガイドなしの透過PNG保存に対応しています。
- 読み込んだ画像はブラウザ内で処理され、送信されません。

## 処理と制約

画像全体を縦横比を維持して800×520内に収めます。カーブ編集では入力画像の位置・サイズ・向きは変えません。
カーブの弧長・法線座標を使い、元の座標からの差分として逆変換します。
Smear量は伸長の制御値で、各ピクセルの実移動距離ではありません。
Radius外は元画像をそのまま保持し、内側では距離に応じて変位を弱めます。
筋は法線方向の固定ノイズで変位量を変えて作ります。
これは一般的な流体シミュレーションではなく、1本の曲線による局所変形の試作です。
半径はカーブ全体で共通です。自由形状の追加マスクや複数カーブにはまだ対応していません。
Radiusは出力の変形範囲を制限します。読み取る元画像の領域を限定する素材選択マスクではありません。
背景付き画像では範囲内の背景も変形します。
鋭い曲がり・自己交差・狭いRadiusで大きく伸ばす場合は継ぎ目や折り返しが出ることがあります。
画像端で出力は切れます。元サイズでの書き出し、動画、AEへの組み込みは未対応です。
